# 996M2 Reloader

用于 996 引擎 M2Server(老三端) 的重新加载辅助工具。程序会自动识别 M2Server 窗口中的“控制 -> 重新加载”菜单项，并通过快捷键批量执行选中的重载项目。

## 功能特性

- 自动查找标题包含 `996引擎` 和 `KUAFU` 的 M2Server 窗口
- 验证目标进程为 `M2Server.exe`
- 自动读取“控制 -> 重新加载”菜单下的子项
- 支持勾选需要执行的重载项目
- 按 `Ctrl+S` 批量执行已勾选项目
- 支持全选、取消全选、刷新菜单
- 支持修改 M2Server 日志窗口字体和字号
- 支持记录 M2Server 主窗口与客户端控制台窗口的屏幕、坐标和尺寸
- 启动和按 `Ctrl+S` 时优先恢复自定义窗口布局，没有自定义记录时使用内置默认布局
- 支持清除自定义窗口布局记录
- 自动保存字体配置和勾选项到 `config.json`
- 启动后默认隐藏到系统托盘
- 关闭窗口时最小化到托盘，托盘菜单支持显示和退出

## 运行环境

- Windows
- Python 3.x
- 目标程序：996 引擎 `M2Server.exe`

## 依赖安装

```powershell
pip install pywin32 pywinauto psutil pystray pillow
```

## 使用方法

1. 启动 996 引擎的 `M2Server.exe`。
2. 运行本工具：

   ```powershell
   python 自动重载.pyw
   ```

3. 程序启动后默认进入系统托盘。
4. 双击托盘图标或右键选择“显示”打开主界面。
5. 点击“刷新”读取 M2Server 的重新加载菜单。
6. 勾选需要自动执行的重载项。
7. 将 M2Server 主窗口和客户端控制台窗口调整到需要的位置后，点击“记录窗口”。
8. 程序启动时会自动恢复窗口布局；在任意窗口按 `Ctrl+S` 时也会先恢复窗口布局，再按顺序执行已勾选的重载项。

“记录窗口”要求 M2Server 主窗口和客户端控制台窗口同时存在、可见且未最小化；任一窗口缺失都会提示并中止记录。“清除记录”后，程序恢复使用内置默认布局。

恢复窗口时会先调整外框，再按实际客户区尺寸补发 `WM_SIZE` 并刷新窗口；对经典控制台还会依据客户区和字体单元格同步字符缓冲区及水平视口，并在控制台异步重算后再次复同步，避免从较大尺寸缩小后出现水平滚动、左侧截断或窗口被缓冲区反向缩窄。

## 配置文件

程序会在同目录下读写：

```text
config.json
```

当前保存内容包括：

- `font_name`：日志窗口字体
- `font_size`：日志窗口字号
- `selected_items`：已勾选的重载菜单项
- `window_layout`：可选的自定义窗口布局，包含 M2Server 主窗口和客户端控制台窗口的屏幕、坐标、宽度和高度

示例：

```json
{
  "font_name": "Segoe UI",
  "font_size": 22,
  "selected_items": [
    "&QFunction\tCtrl+F"
  ],
  "window_layout": {
    "m2server": {
      "screen": "\\\\.\\DISPLAY2",
      "x": -760,
      "y": 5,
      "width": 754,
      "height": 516
    },
    "client_console": {
      "screen": "\\\\.\\DISPLAY2",
      "x": -765,
      "y": 517,
      "width": 759,
      "height": 519
    }
  }
}
```

## 默认重载项目

首次运行且没有保存配置时，程序会默认勾选以下类型的项目：

- 物品数据
- 怪物数据
- 重载爆率
- 重载套装
- Buff
- LuaFunc 函数库
- LuaCond 条件函数库
- QFunction
- QManage
- 重载机器人
- 所有 NPC

实际显示内容以 M2Server 菜单为准。

## 注意事项

- 本工具仅适用于 Windows。
- 需要先启动 M2Server，否则会提示未找到目标窗口。
- 目标窗口标题需要包含 `996引擎` 和 `KUAFU`。
- 如果 M2Server 重启过，建议点击“刷新”重新连接。
- 默认窗口布局采用当前检测到的 M2Server 和客户端控制台布局；存在 `window_layout` 自定义记录时优先使用自定义值。
- 窗口布局坐标使用 Windows 虚拟桌面坐标，多显示器位于主屏左侧时可能出现负数坐标。
- `Ctrl+S` 会作为全局触发键使用，注意避免和其他工具流程冲突。
- 托盘图标默认读取项目目录内的 `icon.ico`，读取失败时会使用内置纯色图标。
