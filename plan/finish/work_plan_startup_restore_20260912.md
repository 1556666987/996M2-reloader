# 工作计划：启动时恢复窗口布局

## 目标

修复启动自动重载工具后未自动恢复 M2Server 与客户端控制台窗口布局的问题。

## 已确认信息

- 当前实现只在 `Ctrl+S` 流程调用 `_restore_window_layout()`。
- 当前配置没有 `window_layout`，因此应使用默认布局。
- 默认布局：M2Server `(-760, 5, 754×516)`；客户端控制台 `(-765, 517, 759×519)`。
- 计划文件：`plan/work_plan.md`，完成后归档至 `plan/finish/`。
