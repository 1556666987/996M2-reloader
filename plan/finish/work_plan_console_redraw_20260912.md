# 工作计划：修复控制台窗口恢复后的显示异常

## 目标

修复客户端控制台窗口从较大尺寸恢复到较小尺寸后，日志内容显示错乱、需要手动调整窗口才能恢复的问题。

## 已确认信息

- 目标窗口是 `ConsoleWindowClass`。
- 当前代码在 `SetWindowPos` 后使用外框宽高补发 `WM_SIZE`。
- Windows `WM_SIZE.lParam` 要求传递客户区宽高；手动调整窗口会自动发送正确的客户区尺寸。
- 计划文件：`plan/work_plan.md`，完成后归档至 `plan/finish/`。
