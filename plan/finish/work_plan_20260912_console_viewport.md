# 工作计划：修复控制台窗口恢复后的水平截断

## 目标

修复客户端控制台从较大尺寸恢复到目标尺寸后，控制台内部视口与字符缓冲区不一致，导致水平滚动条、左侧截断和日志显示异常的问题。

## 已确认信息

- 目标窗口是 `ConsoleWindowClass`，标题为 `E:\龙龙火龙七改\client\game.exe`。
- 当前目标外框可恢复到 `759x519`，但实际控制台视口为约 `47` 列、缓冲区为 `90` 列，水平滚动位置为 `43`。
- 现有实现按 `GetCurrentConsoleFont()` 的字体像素和客户区像素计算列数；在当前 DPI 环境下得到的列数与控制台实际视口不一致。
- 计划文件：`plan/work_plan.md`；完成后归档到 `plan/finish/`。
